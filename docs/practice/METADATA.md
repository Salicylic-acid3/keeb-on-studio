# 機種メタデータ（セットアップガイド用）

セットアップガイドが配置案を作るために、機種ごとに持つ小さな JSON（SPEC §8）。
置き場所は `src/practice/data/keyboards.json`、キーは機種 ID。

## 新機種を登録するとき

1. 機種をいつもどおり登録する（レイアウト・デフォルトキーマップ）。
2. `keeb-on.studio/practice?meta&keyboard=<機種ID>` を開く。ファイルに無い機種は
   デフォルトキーマップからの推定値が入った状態で開く。
3. 役割（親指キー・ホームロウ・記号スロット・レイヤーキー・Esc/Tab/CapsLock）を
   選び、描画上のキーをクリックして付け外しする。サイズクラス・分割・
   「30%に挑戦」を出すかも同じ画面で決める。
4. 「確認済み」にチェックして「JSON をコピー」し、`keyboards.json` に貼る。

## 項目

| 項目               | 意味                                                                                               |
| ------------------ | -------------------------------------------------------------------------------------------------- |
| `sizeClass`        | `"30" / "40" / "60" / "75" / "80" / "pad"`。pad はテンキーなどガイド対象外                         |
| `defaultGuide`     | 最初に出るガイド系統（`"30" / "40" / "60"`、pad は null）。75 / 80 は 60 系統                      |
| `allowGuide`       | 切り替えられる系統。40 なら `["30","40"]`（「30%に挑戦」が出る）                                   |
| `split`            | 分割キーボードかどうか                                                                             |
| `thumbKeys`        | 親指で押せるキー（`pos` と手 `hand`）。親指スペース計測と親指キー提案に使う                        |
| `homeRow`          | 左右のホームロウ 4 キーずつ。30% の Home Row Mods 提案に使う                                       |
| `fixedKeys`        | Esc / Tab / CapsLock のデフォルト位置（無ければ null）。ガイドでは選ばせず「置き換えるか」だけ問う |
| `symbolSlots`      | ベース層で記号を置けるスロット。省略時はデフォルトキーマップの記号位置                             |
| `defaultLayerKeys` | デフォルトキーマップのレイヤーキー（`pos`・`layer`・手）                                           |
| `reviewed`         | 人が見て直したら true                                                                              |

`pos` は機種のキー一覧（キーマップのバインディングと同じ順）のインデックス。

既存機種分は `estimateMeta()` の推定値で初期化してあり、`reviewed: false` のまま。
推定のルール: キー数 20 以下は pad、幅 11u 未満は 30、14u 以下は 40、16u 以下は 60、
17.5u 以下は 75、それ以上は 80。親指キーは最下段の Space とその左右 1.75u 以内。
ClickBoard CyberMini（40）と ErgoTrack（60・分割）は手で直してある。
